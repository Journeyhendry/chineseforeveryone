# Xué Mandarin

Xué Mandarin adalah situs belajar Mandarin interaktif dan gratis untuk semua orang. Materinya disusun dari HSK 1 terlebih dahulu, lalu dilanjutkan ke level berikutnya. Setiap materi dijelaskan dalam bahasa Indonesia dan Inggris, dilengkapi permainan, visual, dan audio.

## Menjalankan di komputer

Pastikan Node.js 22 atau yang lebih baru sudah terpasang.

```bash
npm ci          # pasang dependensi sesuai package-lock.json
npm run dev     # jalankan server pengembangan
npm run build   # buat hasil build di folder dist/
```
