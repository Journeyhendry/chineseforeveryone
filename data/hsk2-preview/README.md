# HSK 2 pratinjau

Kata dari daftar HSK 3.0 tahun 2021 (level 1, 500 kata) yang **tidak** masuk 300 kata HSK 1 silabus 2025. Data tidak dibuang; disimpan di sini untuk dipakai lagi saat level 2 dibuat. Situs belum menampilkannya.

- `words.json`: 234 kata, skema sama dengan `data/hsk1/words.json`, id lama tetap, `hsk: 2`, `previewFrom: "hsk1-2021"`.
- `visuals.json`: deskripsi visual kata-kata ini.
- `scenes.json`: adegan kata-kata ini (`unitId` berbentuk `2021:uNN`, unit lama). File SVG-nya tetap di `public/art/scenes/` (tidak dihapus), tetapi tidak ada di `index.json`.
- Dibuat oleh `npm run build:words` (daftar kata) dan dipindah dari data lama pada task 2b.
