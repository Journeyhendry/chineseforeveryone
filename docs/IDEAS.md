# IDEAS — ide dari pemilik

Ide baru dari pemilik dicatat di sini. Sesi kerja **tidak** mengerjakan ide dari daftar "Ide parkir". Ide baru dikerjakan hanya setelah dipindah ke "Disetujui masuk v1" **dan** sudah dibuatkan task di `docs/BUILD_PLAN.md` bagian 4 + baris di `docs/PROGRESS.md`.

## Disetujui masuk v1

- Tahap 0 "Dasar sebelum HSK 1" → task 0 (2026-11-22)
- HSK 1 = 300 kata silabus 2025 → task 2b (2026-11-22)
- Dialog alami sehari-hari (rumah, sekolah, pasar, dst.) → task 3d (2026-11-22)

## Ide parkir (untuk nanti / v2)

- Login Google + progres pindah antar perangkat.
- Tampilan khusus HP dan latihan menulis huruf dengan jari.
- HSK 2 dan seterusnya.
- Relawan penutur asli untuk memeriksa materi.
- **Pelajaran kecil + ujian unit (versi campur, usul pemilik 2026-11-25; dikerjakan SETELAH semua task selesai, hanya bila pemilik bilang "buat task 11")**
  - Satu unit dipecah 4–5 pelajaran kecil (±4 kata, ±5 menit). Isi: kenalan kata, latihan campur (tebak gambar, dengar-pilih, pasang, tulis huruf, susun kalimat, mini dialog), soal salah muncul lagi di akhir, bintang 1–3.
  - Pelajaran terbuka berurutan → ujian unit (soal DIACAK dari bank soal, beda tiap ujian) → lulus 80% buka unit berikut. Belum lulus → lihat yang salah → belajar lagi → ujian ulang. 100% → unit emas.
  - Tanpa hati/energi. Tanpa login (nilai di perangkat). "Tes loncat" tetap ada.
  - Dipakai ulang: data unit/kata/kalimat/dialog, suara, ilustrasi, game, progres. Baru: peta jalur berliku, pengacak + bank soal, layar hasil + belajar ulang. Progres lama harus tetap terbaca (unit tetap 21, pelajaran kecil hanya membagi kata unit).
  - Perkiraan: soal acak + lulus + ulang ±1 sesi; pelajaran kecil ±2–3 sesi.
- **Animasi sesuai contoh kalimat + dialog per kata (usul pemilik 2026-11-25; 6b DIJEDA karena ini)**
  - Gambar adegan menggambarkan 1 contoh kalimat utama per kata (balon bicara berisi kalimatnya), bukan kata saja.
  - Dialog tidak di luar: mini dialog 2 baris di tiap kartu kata (dengan suara), atau percakapan itu sendiri jadi animasi. Dialog panjang per unit jadi "cerita unit".
  - Tahap 1–3 (unit 1–12, 177 adegan) sudah ada dan bisa diadaptasi (ganti isi balon + pilih kalimat yang cocok).

  - Keputusan pemilik 2026-11-25 (lanjutan): default 1 kalimat per kata; pakai dialog hanya untuk kata yang butuh dialog agar paham (mis. partikel 吗/呢/吧, sapaan, tawar-menawar).
  - Kalimat/dialog hanya memakai kata & data yang SUDAH ada (kata unit ini + unit sebelumnya, 300 kata HSK 1 + ungkapan santai yang sudah lolos cek). Tujuan: pelajar mengulang dan mengingat — "tulisan ini pernah dipakai di materi sebelumnya, ternyata fungsinya begini".
  - Di animasi/kalimat, kata yang sudah dipelajari bisa disentuh: muncul arti + tautan "dipelajari di Unit N". Kata baru disorot warna.
  - Syarat data: cek otomatis kosakata (sudah ada untuk dialog) diperluas ke kalimat utama tiap kata; kalimat yang memuat kata di luar unit ini + sebelumnya tidak dipakai.
